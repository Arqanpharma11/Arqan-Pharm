# Free notification backend
Deploy notification-worker.js as a separate Cloudflare Worker (not the Telegram worker). Set FCM_SERVICE_ACCOUNT_JSON as an encrypted secret using a dedicated service account in arkan-pharm with only required FCM permissions. Set FIREBASE_WEB_API_KEY to the existing project web API key. Never commit credentials. Verify GET health and test enroll/send/unsubscribe. Then set the deployed HTTPS URL in notifications/portal.js in place of the Cloud Functions URL. Do not change index.html, sw.js or Firestore rules. No Blaze upgrade required. Public enrollment is for public offers only; add rate limiting where available. Do not send to real users until test succeeds.
